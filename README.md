## Project Overview

Developed an interactive Business Intelligence dashboard using Microsoft Power BI to analyze 1 million e-commerce transaction records.

The project focuses on analyzing sales performance, product trends, customer purchasing behavior, payment preferences, and delivery operations to generate meaningful business insights and support data-driven decision-making.

## Project Objectives

- Analyze overall e-commerce sales and revenue performance.
- Identify top-performing product categories, brands, and products.
- Understand customer distribution and payment preferences.
- Evaluate delivery performance and shipping time.
- Analyze product return patterns and identify improvement opportunities.

## Dataset Information

- Dataset Size: 1,000,000 transaction records
- Data Type: E-commerce transaction-level data
- Key Fields: Product, Category, Brand, Price, Discount, Customer, Location, Payment Method, Purchase Date, Delivery Status and Returns.

## Key Business Insights

1. Electronics contributes the highest share of revenue among the analyzed product categories.
2. Delivery status analysis highlights a significant proportion of delayed transactions, indicating an opportunity to improve logistics operations.
3. Payment transactions are distributed across multiple payment methods, showing the importance of maintaining payment flexibility.
4. Category-wise return analysis helps identify product segments that require further investigation into quality and customer satisfaction.

## Business Recommendations

- Improve delivery operations by investigating delayed transactions.
- Monitor inventory and supplier performance in high-revenue categories.
- Investigate product return reasons and customer feedback.
- Maintain multiple payment options to support customer preferences.

## Technical Implementation

- Cleaned and transformed transaction data using Power Query.
- Developed DAX measures for revenue, transaction volume, average transaction value, return rate and shipping performance.
- Created interactive KPI cards, bar charts, column charts, donut charts and trend analysis visuals.
- Implemented slicers and cross-page navigation for interactive reporting.
- Designed a multi-page dashboard with a dedicated landing page.
